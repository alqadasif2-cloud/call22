# نسخي الاحتياطي والعارض المشفّر (نسخة الويب المتكاملة)

تطبيق ويب عربي متكامل للنسخ الاحتياطي الشخصي واستعراض السجلات المشفّرة طرفيًا (**سجل المكالمات، الرسائل النصية، ومقتطفات الحافظة اليدوية**)، مبني بـ **React + TypeScript + Vite** ومتصل بـ **Firebase Authentication** و**Cloud Firestore** مع توافق تشفيري كامل مع حزمة `cal1`.

## المزايا الأساسية

- **تشفير طرفي كامل على الجهاز (End-to-End Encryption):**
  - اشتقاق مفتاح `AES-256` عبر `PBKDF2-HMAC-SHA256` بعدد **310,000 تكرار** داخل المتصفح عبر `Web Crypto API`.
  - تشفير كل سجل بـ `AES-256-GCM` مع بيانات مصادقة إضافية (`AAD = id|type|ts`) بحيث لا تغادر عبارة المرور ولا المفتاح جهازك أبدًا.
- **منع التكرار الحتمي:**
  - حساب معرّف حتمي مقتطع من بصمة `SHA-256` لكل مكالمة أو رسالة أو نص حافظة لمنع التكرار محليًا (`IndexedDB`) وفي السحابة (`Firestore`).
- **حماية الحافظة من البيانات الحساسة:**
  - حفظ يدوي صريح فقط (دون أي مراقبة خلفية) مع مرشّح يحجب تلقائيًا كلمات المرور وأكواد التحقق (`OTP`) والأرقام السرية القصيرة وأرقام البطاقات البنكية المطابقة لخوارزمية `Luhn`.
- **الاستيراد والتصدير الموثّق:**
  - استيراد ملفات المكالمات بصيغة `CSV` والرسائل بصيغتي `XML` (*SMS Backup & Restore*) و`CSV`.
  - تصدير البيانات بصيغ `CSV` (مع `UTF-8 BOM` لدعم العربية في الجداول)، `JSON`، `TXT`، وأرشيف `ZIP` مجمّع يتضمن `manifest.json` مع إعادة قراءة الملفات والتحقق من تطابق بصمات `SHA-256` قبل الحفظ.
- **قواعد أمان صارمة (`firestore.rules`):**
  - عزل كامل لكل مستخدم، التحقق من ملكية الجهاز الأب (`Master Gate`)، فرض حدود الأحجام والأنواع، ومنع التعديل على جذر التشفير `meta/crypto` بعد إنشائه.

## هيكل المستودع الموحّد (الويب + أندرويد + GitHub Actions)

يجمع هذا المستودع بين **نسخة الويب المتكاملة** و**تطبيقي أندرويد الأصليين** مع مسار البناء والاختبار التلقائي عبر **GitHub Actions**:

- `src/` و`firestore.rules`: تطبيق الويب المتكامل (React + TypeScript + Vite) المتصل مباشرةً بـ Firebase Auth وCloud Firestore.
- `core/` و`backup-app/` و`viewer-app/`: وحدات أندرويد الأصلية (Kotlin + Jetpack Compose + Gradle) لبناء ملفي `APK` (`backup-app` و`viewer-app`).
- `firebase/` و`firebase/rules-test/`: قواعد الأمان والفهارس واختبارات محاكي Firestore الخاصة بمسار التكامل المستمر (`npm install --prefix firebase/rules-test`).
- `.github/workflows/build.yml`: مسار GitHub Actions لتشغيل اختبارات الوحدة، اختبار قواعد Firebase على المحاكي، وبناء ملفي `APK` (راجع `SETUP_AR.md` لإضافة السر `GOOGLE_SERVICES_JSON_BASE64`).
